USAGE:
  stow-manager [OPTIONS] <COMMAND> [ARGS...]

CORE COMMANDS:
  stow <pkg...>             Stow one or multiple packages
  unstow <pkg...>           Unstow one or multiple packages
  restow <pkg...>           Restow (unstow & stow) one or multiple packages
  all                       Stow all packages in dotfiles repository
  diff [pkg...]             Preview pending symlink, backup, and dependency changes
  scan [pkg...]             Scan packages to auto-detect missing tools & plugins

PACKAGE MANAGEMENT (pkg):
  pkg create <name>         Scaffold a new package directory & .stowdeps manifest
  pkg remove <name...>      Safely unstow and remove package directories
  pkg list                  List packages with status ([STOWED], [PARTIAL], [UNSTOWED])

DEPENDENCY MANAGEMENT (deps):
  deps add <pkg> <dep>      Add dependency/conflict (--required, --optional, --conflict)
  deps edit <pkg> <dep>     Edit existing dependency classification
  deps remove <pkg> <dep>   Remove a dependency or conflict entry
  deps show <pkg>           Display raw .stowdeps manifest contents
  deps target <pkg> <path>  Set per-package target directory in .stowdeps manifest

DIAGNOSTICS & REPAIR:
  check [pkg...]            Verify dependencies and symlink integrity for packages
  check symlinks            Scan for broken or unmanaged orphan symlinks
  fix conflicts             Unfold directory symlinks to resolve collisions

CONFIGURATION (config):
  config show               Display active configuration & repositories
  config set <key> <val>    Set primary dotfiles repository or target directory
  config add <path>         Add an additional dotfiles repository (multi-repo)
  config remove <path>      Remove a dotfiles repository from config

OPTIONS:
  -d, --dotfiles-dir <path> Override dotfiles repository path for current command
  -t, --target-dir <path>   Override target directory for current command
  -y, --install             Auto-confirm installation of missing dependencies
  -n, --dry-run             Preview disk changes without modifying disk
  -s, --save                Save command-line directory overrides (-d/-t) to config
  -h, --help                Display this help manual
